Возможности

Всё, что нужно для скачивания — в одном приложении

🎨

Темы и праздники

3 обычные темы (Тёмная, Бежевая, Красная) и 4 праздничные — с падающими тыквами, снежинками и цветами.

🎵

Встроенный плеер

Плеер для MP3 прямо в приложении: пауза, стоп, прогресс-бар и плейлист из истории скачанного.

🎛

Любое качество

Динамические кнопки качества с размером файла. Поддержка 4K, 1080p, 320 kbps и других форматов.

🖼

Обложки и метаданные

Авто-обрезка заливки YouTube Music, вшивание обложки в MP3, метаданные (артист, альбом, год).

📂

Автосортировка

MP3 → Музыка, MP4 → Видео, архив → Архив. Всё автоматически раскладывается по папкам.

📦

Автообновление yt-dlp

Свежая версия yt-dlp скачивается с PyPI в фоне. Никаких ручных обновлений.
